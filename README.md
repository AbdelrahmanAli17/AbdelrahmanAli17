## Summary

Bioinformatics researcher and software developer working at the interface of mass spectrometry-based proteomics, metabolomics, and machine learning. I build analysis pipelines and open-source tools for multi-omics data, and apply integrative and AI-driven methods to uncover disease mechanisms, with a focus on cancer biology.

I am currently a Teaching Assistant and Research Associate at Badr University in Assiut (BUA), Faculty of Artificial Intelligence and Data Management, and an MSc candidate in Biotechnology (Genetics) at Cairo University.

**Research interests:** Software development, deep learning for multi-omics integration, network biology, AI-driven systems biology, precision medicine.
